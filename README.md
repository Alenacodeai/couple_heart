# Couple Heart — Москва ❤️ Ханчжоу

Готовая упрощенная версия для GitHub Pages.

## Что внутри
- новая широкая картинка с большим количеством космоса;
- без кнопки «Войти»;
- без регистрации;
- один общий счетчик сердечек;
- одна кнопка ❤️;
- новое сердечко раз в 30 минут на каждом устройстве;
- адаптация под телефон.

## Что загрузить в GitHub
Замените содержимое репозитория этими файлами:
- index.html
- supabase_common_counter.sql
- assets/cover.png

## Supabase
1. Откройте SQL Editor.
2. Выполните `supabase_common_counter.sql`.
3. В `index.html` вставьте:
   - SUPABASE_URL
   - SUPABASE_ANON_KEY


## Premium bottom panel
Сделана стеклянная плашка только в нижней части экрана. Верх оставлен для космоса и Земли.
